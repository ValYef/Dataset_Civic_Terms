# Contributing / Як долучитися

Thank you for your interest in improving the Ukrainian Civic Terms Dataset.
Дякую за ваш інтерес до вдосконалення набору даних «Українські громадянські терміни» (Ukrainian Civic Terms Dataset).

## How to contribute / Як долучитися

1. Fork the repository. / Створіть форк репозиторію.
2. Create a new branch. / Створіть нову гілку.
3. Add or edit entries. / Додайте або відредагуйте записи.
4. Submit a Pull Request. / Надішліть запит на злиття (Pull Request).

## Contribution Guidelines / Рекомендації щодо наповнення

Please ensure that:
Будь ласка, переконайтеся, що:

- content is written in Ukrainian / контент написаний українською мовою;
- information originates from reliable and publicly available sources / інформація взята з надійних і загальнодоступних джерел;
- entries are relevant to civic engagement, public participation, human rights, gender equality, social development, or related topics / записи стосуються громадянської активності, участі громадськості, прав людини, гендерної рівності, соціального розвитку або суміжних тем;
- questions are phrased naturally / запитання сформульовані природною мовою;
- answers are concise and informative / відповіді є лаконічними та інформативними;
- duplicate entries are avoided / немає дублюючих записів.

## Suggested Format / Рекомендований формат

| Question | Answer |
|-----------|---------|
| Що таке громадянське суспільство? | Сукупність незалежних від держави суспільних інститутів та ініціатив. |

## Code of Conduct / Кодекс поведінки

Please maintain respectful and constructive communication with all contributors.
Будь ласка, підтримуйте шанобливе та конструктивне спілкування з усіма учасниками/цями проєкту.
